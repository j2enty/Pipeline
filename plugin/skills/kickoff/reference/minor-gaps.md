# Minor 격차 (구현 중 발견 시 결정)

> 원본 kickoff.md.tmpl 의 "Minor 격차" 섹션. 스펙에서 명시적으로 확정되지 않았고, 구현·운영
> 중 실제 케이스가 나타나면 그때 처리.

- **G9** 브랜치 이름 충돌 (상태파일 없고 브랜치만 있는 경우 — 현재는 executor 가 rebase 시도
  후 충돌이면 `immediate` 에스컬)
- **G10** 플래그와 영역 수 불일치 (예: 5영역에 `--serial`) — 현재는 사용자 선택 존중, 경고만
- **G11** `--restart` 시 기존 산출물 정리 범위 확장 — G4-c 의 3옵션으로 시작, 필요 시 세분화
- **G12** Backend 선행 후 런타임 재계산 — 현재는 초기 결정 모드 고정. 재계산 원하면
  `--restart` 후 다시. (OMC degrade 결정도 시작 시 1회 고정.)
- **G13** executor 무한루프 타임아웃 — 현재는 없음. Agent() 기본 타임아웃에 의존. 필요 시 추후 추가
